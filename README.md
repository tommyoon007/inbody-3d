# 인바디 3D · 윤홍기

인바디 기록을 **체형 이미지 변신 시뮬레이터**와 **변신 갤러리**로 보는 개인 PWA.
GitHub Pages: https://tommyoon007.github.io/inbody-3d/

## 화면 구성

| 모드 | 내용 |
| --- | --- |
| 변신 시뮬레이터 | 현재 체형 사진과 목표 체형 사진을 겹쳐 두고, 날짜 슬라이더·`▶ 변화 과정 보기` 진행률에 따라 부드럽게 크로스페이드. 미세한 호흡 효과 |
| 변신 갤러리 | 비포·애프터 비교 슬라이더, 수치 비교표 + **지표별 변화 그래프**, 날짜별 카드, 기록 추가·내보내기 |

두 화면 모두 **상의 탈의 + 검은 스포츠 반바지**(피트니스 바디체크 스타일)로 표현해 복부·가슴·어깨·허벅지 변화가 바로 보입니다.

### 🎯 부위별 업그레이드 · 맞춤 운동 팁

선택한 기록의 `체지방률 · 복부지방률 · 내장지방레벨 · 골격근량`으로 세 부위(복부·내장지방 / 하체 대근육 / 상체·코어)의 필요도를 점수화해 1~3순위로 보여 주고, 순위에 맞춘 주간 운동 계획을 함께 표시합니다. 슬라이더로 날짜를 바꾸거나 목표 체형을 고르면 팁과 주간 계획이 그 상태에 맞게 바뀌고, 목표에 도달하면 "유지·강화 모드"로 전환됩니다.

운동 이름을 몰라도 따라 할 수 있도록 **운동마다 동작 일러스트**를 붙였습니다. `moves.js`에 72×72 뷰박스 인라인 SVG(사람 실루엣 + 움직임 화살표 + 자극 부위 강조)로 정의돼 있어, 이미지 파일 없이 즉시 그려지고 로딩·용량 부담이 없습니다. 일러스트는 모바일 88px·데스크톱 96px로 크게 보여 주고, 관절이 실제 동작처럼 움직입니다(시스템의 '동작 줄이기' 설정과 무관하게 항상 재생). 타일을 누르면 190px 큰 그림 + 세트·횟수 + 초보자용 한 줄 자세 설명 + `유튜브에서 동작 영상 보기` 검색 링크가 담긴 동작 가이드 모달이 열립니다(바탕을 누르거나 Esc로 닫기). 운동을 추가할 때는 `moves.js`에 그림을, `app.js`의 `TIPS`에 `moves` 항목과 `MOVE_GUIDE`에 설명을 추가하면 됩니다.

### 📈 수치 변화 그래프

`수치 비교` 카드 아래에서 체중·골격근량·체지방률·체지방량·BMI·복부지방률·내장지방·인바디점수를 탭으로 전환하며 날짜별 추이를 봅니다. 축 범위는 측정값에 맞춰 자동으로 잡히고(1·2·2.5·5 눈금), 각 점에 수치·날짜가 표시되며 마지막 측정은 민트색으로 강조됩니다. 목표값이 그래프 범위 안에 들어오면 파란 점선으로 함께 그려지고, 범위 밖이면 요약줄에 `목표` 칩으로 표시됩니다. 기기에서 추가한 기록도 바로 반영됩니다.

## 데이터 갱신 방법

새 인바디 결과를 받으면 `data.json`의 `records` 배열에 항목을 추가하고 커밋하면 됩니다.

```json
{
  "id": "2026-11-30",
  "date": "2026-11-30",
  "label": "3차 측정",
  "weight": 85.1,
  "skeletalMuscle": 34.9,
  "bodyFatMass": 23.6,
  "bodyFatPct": 27.7,
  "bmi": 27.5,
  "score": 71,
  "waistRatio": 0.99,
  "visceralFat": 10,
  "bmr": 1702
}
```

- 측정되지 않은 항목은 `null`로 두면 체지방률로 추정합니다 (`estimated` 플래그를 두면 화면에 "추정"으로 표시).
- 목표 프리뷰는 `"goal": true` 항목으로, 항상 타임라인 마지막에 놓입니다.
- 앱에서 직접 추가한 기록은 기기 `localStorage`에 저장되며, `JSON 내보내기`로 받은 파일을 `data.json`에 합치면 모든 기기에 반영됩니다.

## 이미지 변신 규칙

- 타임라인의 마지막 실측 기록까지는 `assets/body-current.webp`, 마지막 실측 → 목표 구간에서 `assets/body-goal.webp`가 슬라이더 값에 따라 opacity로 겹쳐집니다 (`app.js`의 `figureProgress()`).
- 두 이미지는 같은 프레임(900×1350)으로 만들어져 있어 인물 위치가 일치하고, 그래서 크로스페이드가 자연스러운 변신처럼 보입니다.
- 새 체형 이미지를 만들면 같은 크기(900×1350)·구도로 `assets/body-current.webp`(또는 `body-goal.webp`)를 교체하면 됩니다. 원본 PNG를 WebP로 바꾸려면 `python3 -c "from PIL import Image; Image.open('assets/body-current.png').save('assets/body-current.webp','WEBP',quality=92,method=6)"`. 이미지를 교체하면 `index.html`의 `styles.css`·`app.js` 쿼리 버전과 `sw.js`의 `CACHE` 버전을 올려 캐시를 무효화합니다.
- 원본 `assets/body-current.png`·`body-goal.png`는 보관용(사이트는 WebP 사용, 두 파일 합계 약 2.6MB → WebP 약 130KB).

## 파일

- `assets/body-current.webp` — 실측 체형 이미지 (11/26 측정 85.6kg · 29.2% 기준, 원본 `body-current.png`). 새 측정이 쌓여도 새 이미지를 만들기 전까지는 이 이미지를 그대로 씁니다.
- `assets/body-goal.webp` — 목표 체형(75.0kg · 17.5%) 이미지 (원본 `body-goal.png`)
- `index.html`, `app.js`, `styles.css` — 화면·변신 로직·스타일 (외부 라이브러리 없음)
- `moves.js` — 운동 동작 일러스트 SVG 모음 (`app.js`에서 `import { MOVES }`)
- `sw.js`, `manifest.json` — 오프라인 PWA
